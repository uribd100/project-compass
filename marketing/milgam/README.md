# ערכת מילגם — עותק עבודה

מצגת וחומרי הפגישה של **סימפליפאיי × מילגם**.

## מקור קנוני
הבית האמיתי של הקבצים האלה הוא הריפו `uribd100/simplifai-website`, בנתיב:

```
preview/milgam/
```

ומתפרסם בכתובת החיה: **https://simplifai.co.il/preview/milgam/**

זהו עותק עבודה שהובא לכאן כדי לאפשר עריכה תחת git בסשן הנוכחי (שהיקפו `project-compass` בלבד).
**כל שינוי שנרצה להעלות לאתר החי צריך לחזור ל-`simplifai-website/preview/milgam/`** ולהידחף משם.

## קבצים
- `index.html` — מרכז הפגישה (מקשר לכל המסמכים + למערכת PM-ENG)
- `deck.html` — מצגת ההיכרות (14 שקופיות, קובץ HTML יחיד, ניתן לעריכה)
- `deck.pdf` — גרסת PDF של המצגת
- `leave-behind.pdf` — וואן-פייג'ר להשארה
- `discovery-sprint-proposal.pdf` — הצעת תקופת גילוי
- `capability-demo-script.pdf` — סקריפט הדגמת יכולות
- `prep-brief.pdf` — תדריך אסטרטגי לפגישה

## קשור
- מערכת ניהול הפרויקטים **PM-ENG** (נבנתה ב-Lovable): https://pm-eng.lovable.app/
