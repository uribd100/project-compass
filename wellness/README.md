# מצפן בריאות 🧭❤️

אפליקציית בריאות ואורח חיים אישית (PWA) שנבנתה במיוחד לאורי — מערכת אחת שמרכזת
אימון בטוח-לב, מוביליטי ויוגה, תזונה, שינה וגמילה מעישון, ומכוונת לפעולה בכל יום.

> **בטיחות:** האפליקציה נבנתה לפי עקרונות שיקום לבבי (פוסט-MI, EF ~45%, חוסם בטא → עצימות
> לפי RPE ולא דופק). היא כלי מלווה ואינה תחליף לייעוץ הקרדיולוג.

## הרצה מקומית
```bash
cd wellness
npm install
npm run dev      # http://localhost:8090
```
בנייה לפרודקשן: `npm run build` ואז `npm run preview`.

## תכונות
- **בית** — דשבורד "הפעולות של היום", סטריקים, נדג'ים חכמים, טבעת מים.
- **אימון** — תוכנית שלבית (4 שלבים) עם נגן אימון, שער בדיקת סימני-אזהרה לפני/אחרי, תקרת RPE, ושער קידום שלב.
- **גמילה** — סטריק נקי, כסף שנחסך, תיעוד חשק מהיר, מפת טריגרים, אסטרטגיית גמילה מדורגת.
- **תזונה** — ים-תיכוני + שכבת גאוט, תיעוד ארוחות והידרציה.
- **שינה** — תיעוד לילה, גרף שבועי, שגרת הרגעה, מידע על קנאביס ושינה.
- **מוביליטי ויוגה** — רוטינות עדינות + מצב התקף גאוט.
- **סקירה שבועית** — מדדים, מגמת RPE, ניצחון + פוקוס.
- **ספרייה** — מקורות מצוטטים (AHA, NHS, CDC, ACR, NIDA, משרד הבריאות).
- **כרטיס חירום** — כפתור צף תמידי (101, תרופות, סימני אזהרה).

## נתונים וסנכרון
- **Local-first:** כל הנתונים נשמרים מקומית ב-IndexedDB. עובד אופליין.
- **סנכרון ענן (אופציונלי):** Supabase — ראה `supabase/README.md`.

## פריסה
פריסה מומלצת ל-**Vercel/Netlify** עם Root Directory = `wellness/`, build `npm run build`, output `dist`.
PWA ניתנת להתקנה מהדפדפן ("הוסף למסך הבית").

## טכנולוגיות
Vite · React 18 · TypeScript · Tailwind · Radix UI · Recharts · idb · vite-plugin-pwa · (Supabase אופציונלי).
